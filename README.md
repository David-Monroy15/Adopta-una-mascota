# 🐾 Adopta una Mascota

## 📄 Descripción del proyecto
Proyecto web colaborativo desarrollado para un refugio de animales sin fines de lucro. Su objetivo principal es concientizar sobre la adopción responsable, mostrar información sobre el refugio, presentar tarjetas de mascotas disponibles para adopción, una sección de ubicación y un formulario de contacto funcional. Todo diseñado con un enfoque responsivo y limpio.

## 📌 Secciones de la página
1. **Encabezado (Hero Header):** Barra de navegación fija con el logotipo institucional y enlaces rápidos a cada sección.
2. **Sección Principal (Hero):** Presentación atractiva con eslogan y llamado a la acción (*Call to Action*).
3. **Sobre Nosotros:** Misión del refugio, datos curiosos y valores institucionales destacados.
4. **Adóptame:** Tarjetas informativas de mascotas en adopción con imágenes y descripciones detalladas con efectos visuales (*hover*).
5. **Visítanos:** Información de horarios, dirección y mapa interactivo de ubicación.
6. **Contáctanos:** Formulario interactivo para comunicación directa y pie de página con accesos a redes sociales.

## 💻 Comandos de Git utilizados
Durante el desarrollo de este proyecto se utilizó un flujo de trabajo basado en ramas (`feature branches`), commits atómicos y fusiones (`merge`), empleando los siguientes comandos principales:

* **Crear y cambiar a una rama nueva:**
  git bash
  # Cambiar
  git switch -c nombre-de-la-rama

**¿Qué fue lo más difícil del trabajo con ramas?**
Lo más difícil al trabajar con diferentes ramas fue mantener sincronizados los cambios de todos los integrantes y coordinar correctamente los archivos compartidos (como el archivo styles.css y index.html). Al momento de hacer la integración final (merge) hacia la rama principal (main), surgieron algunos conflictos en las líneas de código donde varios tocamos las mismas secciones, lo que requirió revisar cuidadosamente cada conflicto para no sobrescribir el trabajo de los demás y asegurar que el diseño responsivo y visual se mantuviera funcional.
